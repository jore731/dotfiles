# Official Azure Public Service Icons V24

The `Azure_Public_Service_Icons/Icons/` directory contains the official SVG
icons extracted from Microsoft's `Azure_Public_Service_Icons_V24.zip`.

These assets are kept alongside, rather than merged into, the Excalidraw-native
library because the Microsoft archive contains SVG files and no
`.excalidrawlib` elements. Use the SVGs directly in Excalidraw or convert
individual assets when an Excalidraw-native icon is required.

The archive also included Microsoft's `Microsoft_Terms_of_Use.pdf`; retain
that license document when redistributing these assets.
