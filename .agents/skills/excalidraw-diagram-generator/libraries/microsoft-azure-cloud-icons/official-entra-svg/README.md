# Official Microsoft Entra Architecture Icons

This directory contains 14 SVG icons extracted from Microsoft's
`Microsoft Entra architecture icons - Oct 2023.zip` package.

The package includes color and black-and-white variants for Microsoft Entra
ID, Entra ID Governance, Entra Internet Access, Entra Private Access, Entra
Verified ID, and the Entra product family, plus a color Entra Workload ID icon.

These assets remain SVG because the source package does not provide
Excalidraw-native library elements. The original ZIP is retained beside this
directory with Microsoft's terms-of-use document.
