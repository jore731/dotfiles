# BASF Presentation Color Book

This document outlines the six official themes generated for BASF presentations. Each theme utilizes a primary accent color and a corresponding lighter background color.

## 1. Dark Blue (Default)

- **Primary Accent** (`$basf-blue`): `#004A96` (RGB: 0, 74, 150)
- **Background** (`$basf-light-bg`): `#E0E9F2` (RGB: 224, 233, 242)

## 2. Light Blue

- **Primary Accent**: `#21A0D2` (RGB: 33, 160, 210)
- **Background**: `#EFF7FD` (RGB: 239, 247, 253)

## 3. Dark Green

- **Primary Accent**: `#007A33` (RGB: 0, 122, 51)
- **Background**: `#E6F2EB` (RGB: 230, 242, 235)

## 4. Orange

- **Primary Accent**: `#F37021` (RGB: 243, 112, 33)
- **Background**: `#FEF4E5` (RGB: 254, 244, 229)

## 5. Red

- **Primary Accent**: `#E4002B` (RGB: 228, 0, 43)
- **Background**: `#FCE5E8` (RGB: 252, 229, 232)

## 6. Soft Black

- **Primary Accent**: `#212427` (RGB: 33, 36, 39)
- **Background**: `#E9E9E9` (RGB: 233, 233, 233)

## Shared Semantic Colors

Regardless of the chosen primary theme, these semantic colors are shared across all presentations to ensure text legibility and brand consistency.

- **Dark Gray / Body Text** (`$basf-dark-gray`): `#3D3D3D` (RGB: 61, 61, 61)
- **Gray / Inactive Text** (`$basf-gray`): `#8C8C8C` (RGB: 140, 140, 140)
- **White / Containers** (`White`): `#FFFFFF` (RGB: 255, 255, 255)
