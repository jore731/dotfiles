## Pipeline Chains (Common Combinations)

### Full Front-End Pipeline
```
Summit (topic landscape)
  → Empathic Design (user deep dive)
    → Jamming (rapid ideation)
      → Idea Pitch (select + fund)
        → BSD (validate business case)
```

### Internal Innovation Sprint
```
Idea Contest (broad internal crowdsourcing)
  → Idea Pitch (select + fund top ideas)
    → BSD (develop business model)
```

### External Innovation Pipeline
```
Open Innovation Challenge (external solvers)
  → Idea Pitch (shortlist finalist presentations)
    → BSD (validate with collaboration partner)
```

### Customer-Led Innovation
```
Empathic Design (observe user context)
  → Customer Co-creation (co-design with key customers)
    → BSD (value proposition + business model)
```

### Rapid Exploration + Ideation
```
Summit (1–2 day strategic exploration)
  → Jamming (rapid prototyping within 2 weeks)
    → Idea Pitch (6–8 weeks later)
```

## Method Selection Guide

| If you need to... | Use |
|-------------------|-----|
| Understand a strategic topic with external experts (30–200 participants) | Summit |
| Discover what users really need — not what they say | Empathic Design |
| Generate tangible prototypes fast with a large, diverse group | Jamming |
| Co-design iteratively with key customers over multiple sessions | Customer Co-creation |
| Collect broad ideas from employees with low effort per participant | Idea Contest |
| Tap external innovators for a technically hard problem | Open Innovation Challenge |
| Select the best ideas and fund them in one event | Idea Pitch |
| Turn a funded idea into an investable business concept | Business Solution Design |

## Shared Design Principles

These principles apply regardless of which method is used:

| Principle | Why it matters |
|-----------|---------------|
| **3-phase structure (Prepare / Execute / Move Forward)** | Events without a Move Forward plan produce insights that go nowhere |
| **Committed Sponsor** | Without authority to fund follow-up, participants' effort is wasted |
| **Diversity** | Homogeneous groups produce incremental ideas; diversity produces discontinuous ones |
| **Challenge statement quality** | The output is bounded by the quality of the input question |
| **Follow-through communication** | Participants who never hear what happened to their contributions will not participate again |
| **Governance clarity** | Who owns the output? Who decides what moves forward? Must be agreed before the event. |
