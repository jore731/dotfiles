# Jamming — Reference Materials

## Jam Day Schedule Template (1-Day Format)

| Time | Activity | Owner |
|------|----------|-------|
| 08:30 | Registration & coffee | Support staff |
| 09:00 | Welcome & context (15 min) | Sponsor |
| 09:15 | Challenge presentation (10 min) | Jam Master |
| 09:25 | Rules & energizer (15 min) | Facilitator |
| 09:40 | Team formation | Facilitator |
| 09:50 | **Ideation Sprint 1** (45 min) | Teams + Facilitators |
| 10:35 | Cross-team sharing (15 min) | All |
| 10:50 | Break | |
| 11:00 | **Ideation Sprint 2** (45 min) | Teams + Facilitators |
| 11:45 | Prototype direction vote | Teams |
| 11:55 | Lunch & informal networking | |
| 12:45 | **Build Sprint** (90 min) — rough prototypes | Teams |
| 14:15 | Cross-team gallery walk (20 min) | All |
| 14:35 | Break | |
| 14:45 | **Refine Sprint** (45 min) | Teams |
| 15:30 | Prepare showcase (15 min) | Teams |
| 15:45 | **Showcase** — each team 5 min + 3 min Q&A | All |
| 17:00 | Closing & next steps | Sponsor + Jam Master |
| 17:15 | Networking & celebration | |

> **Facilitator ratio:** 1 facilitator per 10–15 Jammers. 1 graphic recorder per 20 Jammers.  
> **Time allocation principle:** Ideation ≈ 30% / Building ≈ 50% / Sharing & Refining ≈ 20%

## Jam Day Schedule Template (2-Day Format)

Use for larger Jams (60+ Jammers) or complex challenges requiring deeper exploration.

### Day 1 — Explore & Ideate

| Time | Activity |
|------|----------|
| 09:00 | Opening, challenge framing, team formation |
| 10:00 | **Inspiration inputs** — experts present challenge context (30 min) |
| 10:30 | **Ideation Sprint 1** — diverge widely |
| 12:00 | Lunch |
| 13:00 | **Ideation Sprint 2** — cross-pollinate across teams |
| 14:30 | **Direction vote** — each team selects 1 prototype direction |
| 15:00 | First prototype sketches |
| 17:00 | Day 1 close — share direction with room |

### Day 2 — Build & Showcase

| Time | Activity |
|------|----------|
| 09:00 | Recap + refine direction |
| 09:30 | **Build Sprint** — build rough prototypes (3 hrs) |
| 12:30 | Lunch + gallery walk of in-progress prototypes |
| 13:30 | **Refine Sprint** (90 min) |
| 15:00 | Prepare showcase |
| 15:30 | **Showcase** — 5 min per team |
| 17:00 | Closing & award |

## Organizing Team Roles

| Role | Responsibility | Staffing guideline |
|------|---------------|--------------------|
| **Jam Master** | Owns overall concept, challenge definition, post-Jam follow-up | 1 person |
| **Facilitators** | Keep teams on track, energize, guide prototyping; one per table | 1 per 10–15 Jammers |
| **Graphic recorders / Sketchers** | Visual capture of ideas in real time on large paper | 1 per 20 Jammers |
| **Subject-matter experts** | Provide content input and challenge context; available to teams during Build Sprint | 1–3 |
| **IT / Social media** | Live updates, digital documentation, streaming if applicable | Optional |
| **Filmmaker / Photographer** | Capture the energy and outputs for communication | Optional |
| **Support staff** | Logistics, materials (craft supplies, sticky notes, markers), food & drink | As needed |

## Challenge Crafting Checklist

The challenge is the centrepiece of the Jam. Get this wrong and the entire day produces off-target output.

- [ ] Written as a "How Might We" question (see `references/challenge-statement.md`)
- [ ] Aligned to a real strategic problem the sponsor needs solved
- [ ] Tested with 2–3 people outside the organizing team before the Jam
- [ ] Presented in one sentence — if you need two sentences, it is too complex
- [ ] Accompanied by a short context presentation (max 10 slides) covering background, data, and examples of existing approaches
- [ ] The context presentation does NOT contain the preferred solution

## Prototyping Materials Checklist

Ensure these are available on every table:

- [ ] A3 / A2 paper (multiple sheets per team)
- [ ] Sticky notes (large and small, multiple colours)
- [ ] Markers (thick, thin, multiple colours)
- [ ] Scissors and tape
- [ ] Cardboard / foam board
- [ ] Craft materials (pipe cleaners, felt, string, rubber bands)
- [ ] LEGO or similar building blocks (optional but effective)
- [ ] Plasticine / modelling clay
- [ ] Phone or camera for documentation
- [ ] Timer visible to all team members

## Facilitator Moves — Quick Reference

| Situation | Facilitator move |
|-----------|-----------------|
| Team is debating, not building | "Stop talking — build it. You have 10 minutes." |
| Team is polishing one idea | "What's the alternative? Make a second version in 5 minutes." |
| Team is stuck | "Flip the challenge: what would make this problem worse?" |
| Team is too safe | "What would the most outrageous version of this look like?" |
| Low energy | Call a 3-minute physical energizer |
| Dominant participant | Address quieter members directly: "What do you think about this direction?" |

## Post-Jam Move Forward Checklist

- [ ] Collect all prototypes and document with photos before teams leave
- [ ] Write a 1-page Jam summary within 48 hours: challenge, teams, top prototypes, next steps
- [ ] Share summary with all Jammers (closes the participation loop)
- [ ] Identify top 2–3 prototypes to take forward (Sponsor + Jam Master decide)
- [ ] Connect selected ideas to Idea Pitch or Business Solution Design process
- [ ] Run a retrospective with the organizing team: what worked, what to improve
