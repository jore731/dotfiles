# Business Solution Design — Reference Materials

## Process Overview

BSD moves through three phases: **Explore → Design → Experiment**

```
EXPLORE                         DESIGN                          EXPERIMENT
────────────────────────────    ────────────────────────────    ──────────────────────────
1. Value chain deep dive    →   1. Value proposition        →   Test critical assumptions
2. Map exploration findings →   2. Providing system              with lean experiments
3. Extract key insights     →   3. Profit formula
                                4. Reality check
```

## Tool 1: Buyer Experience Cycle (BEC)

Maps the full customer journey across 6 stages and 6 utility levers. Use it to surface pain points and whitespace for new value propositions.

### The 6 Stages

```
Purchase → Delivery → Use → Supplements → Maintenance → Disposal
```

### The 6 Utility Levers

For each stage, assess performance against each lever:

| Lever | Question to ask |
|-------|----------------|
| **Customer Productivity** | Does the current solution help customers accomplish more in less time? |
| **Simplicity** | Is it easy to buy, use, and understand? |
| **Convenience** | Can customers access it easily, when and where they need it? |
| **Risk reduction** | Does it reduce financial, operational, or health/safety risk? |
| **Fun & Image** | Does it make customers feel good about using or being associated with it? |
| **Environmental friendliness** | Does it minimise environmental impact across the lifecycle? |

### BEC Grid

Fill in each cell: `+` (performs well), `-` (pain point), `?` (unknown / unexplored)

| | Purchase | Delivery | Use | Supplements | Maintenance | Disposal |
|--|----------|----------|-----|-------------|-------------|---------|
| **Productivity** | | | | | | |
| **Simplicity** | | | | | | |
| **Convenience** | | | | | | |
| **Risk reduction** | | | | | | |
| **Fun & Image** | | | | | | |
| **Environmental** | | | | | | |

> Cells marked `-` or `?` are insight candidates. Cluster adjacent pain points — they often reveal a systemic gap that a new solution could address.

## Tool 2: Value Innovation Toolkit (Eliminate–Reduce–Raise–Create)

Challenges what the industry takes for granted. Forces the team to think beyond incrementalism.

| Action | The question | Strategic logic |
|--------|-------------|----------------|
| **Eliminate** | Which factors does the industry take for granted that we should remove entirely? | Cuts cost and complexity |
| **Reduce** | Which factors should be reduced well below industry standard? | Redirects resources away from low-value attributes |
| **Raise** | Which factors should be raised well above the industry standard? | Creates clear differentiation |
| **Create** | Which factors should be created that the industry has never offered? | Unlocks entirely new demand |

### How to use it

1. List the 8–12 factors all competitors currently compete on in your space
2. For each factor, ask the four questions above
3. Map answers onto the grid — the combination of Eliminate, Reduce, Raise, Create defines a new value curve
4. Check: does the resulting value curve differ significantly from competitors? If not, think bolder.

## Tool 3: Value Proposition Canvas

### Customer Profile (left side)

| Element | What to map |
|---------|------------|
| **Jobs to be done** | What tasks, goals, or problems is the customer trying to address? |
| **Pains** | What frustrates them? What risks do they want to avoid? |
| **Gains** | What outcomes do they want? What would delight them? |

### Value Map (right side)

| Element | What to define |
|---------|---------------|
| **Products & services** | What you offer |
| **Pain relievers** | How your offering reduces specific pains |
| **Gain creators** | How your offering creates specific gains |

> **Fit** is achieved when pain relievers and gain creators address the most important jobs, pains, and gains. Do not claim fit until validated with customers.

## Tool 4: Unit of Sales & Pricing Model Options

When designing the profit formula, challenge the default "sell per unit" assumption.

| Model | Description | When to use |
|-------|-------------|-------------|
| **Per unit** | Customer pays per item or quantity | Commodity or transactional; customer bears stock risk |
| **Subscription** | Recurring fee for continuous access or service | Ongoing value delivery; customer values predictable cost |
| **Outcome-based** | Pay per measurable result achieved | High-value, quantifiable outcomes; requires measurement infrastructure |
| **Platform / marketplace** | Revenue from facilitating transactions between parties | Multi-sided market; network effects exist |
| **Freemium** | Free base offering; paid premium tier | Volume acquisition then upsell; works when free tier has genuine value |
| **Bundled solution** | Package of products + services at one price | Reduces price transparency; creates switching costs |

For each critical assumption in the business model, design the smallest possible test before committing resources.

```
│  TIMELINE                                                             │

```

### Experiment types (from cheapest to most expensive)

| Type | Cost | What it tests |
|------|------|--------------|
| Expert interview | Very low | Plausibility of assumption with domain experts |
| Customer interview | Low | Whether customers recognise the problem and value the solution |
| Landing page test | Low | Whether target customers click through to learn more |
| Concierge MVP | Medium | Whether customers will use the solution if delivered manually |
| Prototype test | Medium | Usability and desirability with real users |
| Pilot | High | Whether the full solution works at small scale |
| Market test | Very high | Whether customers will pay at scale |

## Value Chain Exploration: Who to Map

In B2B, explore beyond immediate customers:

| Player type | Why they matter |
|------------|----------------|
| **Direct customers** | Immediate buyers; their needs are usually well-known but often assumed |
| **Customers' customers** | Their end-users drive real demand; often underexplored by BASF |
| **Non-customers** | People who have opted out of the market entirely; their barriers reveal systemic gaps |
| **Suppliers** | Upstream constraints and capabilities that shape what solutions are possible |
| **Distribution partners** | Gatekeepers who shape how the solution reaches end users |
| **Influencers / NGOs** | Shape regulatory environment and customer perception |
| **Service providers** | Financial, transport, and logistics players that support the value chain |

> Opportunities consistently come from outside a company's traditional industry boundaries. Map beyond the familiar.
