# Summit — Reference Materials

## 2-Day Event Programme Template

### Day 1 — Share and Learn

| Time | Block | Format |
|------|-------|--------|
| 08:30 | Registration & networking | Coffee / informal |
| 09:00 | Welcome by BASF sponsor | Plenary (10 min) |
| 09:10 | Keynote: Context setting | External speaker (20 min) |
| 09:30 | Sub-topic deep dives | Parallel sessions × 3 sub-topics (60 min each) |
| 10:30 | Plenary synthesis: What did we learn? | Moderated discussion |
| 11:00 | Break | |
| 11:15 | Expert panel | Q&A panel (45 min) |
| 12:00 | Lunch & networking | |
| 13:30 | Working groups on sub-topics | 3–4 groups (90 min) |
| 15:00 | Break | |
| 15:15 | Group report-outs | Plenary (30 min) |
| 15:45 | Reflection: key themes & tensions | Facilitated (30 min) |
| 16:15 | Close Day 1 | |
| 19:00 | Dinner | |

### Day 2 — Inject, Discuss, Decide

| Time | Block | Format |
|------|-------|--------|
| 09:00 | Recap Day 1 themes | Plenary (15 min) |
| 09:15 | External provocateurs | 2–3 speakers, 15 min each |
| 10:00 | Roundtable discussions | Small groups rotate through topics |
| 11:00 | Break | |
| 11:15 | Prioritization exercise | Dot voting or digital poll |
| 11:45 | Synthesis: top 3–5 priority areas | Facilitated |
| 12:15 | Lunch | |
| 13:30 | Drafting: What should BASF do next? | Working groups |
| 14:30 | Present recommendations | Plenary |
| 15:15 | Closing remarks by BASF sponsor | Plenary |
| 15:30 | Adjourn | |

> **Design principle:** Max 30% of Summit time in plenary presentations. Min 70% in discussion, working groups, or co-creation. Participants are selected for what they *contribute*, not just who they are.

## Organizing Team Roles

| Role | Responsibility |
|------|---------------|
| Sponsor (VP or above) | Provides mandate, is visibly present, commits to acting on outputs |
| Programme manager | Owns logistics, invitations, agenda, venue |
| Facilitator(s) | Designs and runs working sessions; neutral, not a presenter |
| Rapporteur / Documentarian | Captures outputs in real time; produces summary within 48 hours |
| Communications lead | Pre-event promotion, post-event press/internal releases |
| Subject-matter experts | Prepare briefing papers and sub-topic framing |

---

## Participant Selection Criteria

Aim for a mix across these axes:

| Axis | Target |
|------|--------|
| Internal vs. external | 40–60% external participants |
| Function | R&D, business, sustainability, policy, NGO, academia |
| Geography | Relevant regional representation for the topic |
| Seniority | Mix of senior decision-makers and working-level experts |
| Perspective | Include at least 1–2 "provocateurs" — people with unconventional views |

> Avoid: Selecting only people who already agree. Productive tension is the mechanism of insight.

---

## Sub-Topic Selection Checklist

A Summit typically covers 3–5 sub-topics across the 2 days.

- [ ] Each sub-topic is a genuine question (not a conclusion waiting to be confirmed)
- [ ] Sub-topics together cover the full strategic landscape of the main theme
- [ ] Each sub-topic has a designated internal owner who will champion follow-up
- [ ] Input material (briefing papers, trend reports) is prepared per sub-topic
- [ ] Participants with relevant expertise are assigned to each sub-topic session

---

## Post-Summit: Move Forward Steps

1. **Debrief** the organizing team (day after): What worked? What would we change?
2. **Document** within 1 week: key insights, quotes, priority areas, action items
3. **Evaluate** outputs against original goal: Did we answer the strategic question?
4. **Disseminate**: Internal report to leadership + follow-up email to all participants + press/media output if applicable
5. **Connect** the top 3–5 priority areas to internal owners and next steps (e.g., Empathic Design, Jamming)
